1. 설치

  1. 설치 파일 rep-desktop-setup-0.2.56.exe를 받습니다. 정본은 GitHub Releases, 사본은 OneDrive 00. AI\004. 업무도구\부동산업무도구\에 있습니다.
  2. 실행하면 Windows SmartScreen 경고가 뜹니다(서명 없는 파일). 추가 정보 → 실행.
  3. 설치가 끝나면 「부동산업무도구」가 열립니다. 처음 켤 때 문서 AI 도구(Codex·Claude)를 자동으로 함께 설치합니다. 몇 분 걸릴 수 있습니다.
  4. 지금 버전은 왼쪽 맨 아래 v0.2.56 줄에 보입니다. 새 판이 나오면 화면 오른쪽 위에 노란 띠 「새 버전 X 이 나왔습니다」와 내려받기가 뜹니다(켠 뒤 8초, 그 뒤 30분마다, 창으로 돌아올 때도 확인). 누르면 받고, 다 받으면 설치 — 다시 시작. 0단계 준비 표 맨 위 「프로그램 업데이트」에서도 됩니다.

팀원 PC에는 WSL이나 파이썬을 따로 깔 필요가 없습니다. 필요한 것은 전부 설치 파일 안에 들어 있습니다.

왼쪽 맨 위 세 버튼:

  • 폴더 열기 차주 폴더 하나, 또는 분기 폴더(03. WP)를 엽니다.
  • 빠른 조회 차주 없이 주소 하나로 통계·사례만 봅니다(7장).
  • 분기 차주 목록 차주 작업 중에 목록으로 돌아갑니다.

그 아래 진행 띠는 지금 돌고 있는 작업과 남은 시간을 보여 주고, 중지로 멈춥니다.

AI에게 시키기: 차주를 열면 화면 맨 위에 입력칸이 있습니다. 「낙찰사례 2년·시군구로 다시 모아」, 「위치도 넓게」, 「거래사례 AI 추천 다시」처럼 적고 Enter → 판단 AI 가 「실행할 일」을 한 줄로 보여 주면 실행. 버튼을 누른 것과 같게 돕니다. 보고서 기입은 여기서 하지 않습니다(기입 단계에서 직접).

① 평가보고서 템플릿

  1. 준비 표 「평가보고서 템플릿」 행의 템플릿 고르기.
  2. 이번 분기 공유 폴더의 New Temp_v… .xlsm 를 고릅니다. 원본은 건드리지 않고 차주마다 복사본에 씁니다.
  3. 한 번 고르면 늘 최신 판을 씁니다 — 차주를 열 때 그 템플릿 폴더와 마지막으로 고른 템플릿 폴더에서 _v 번호가 가장 큰 New Temp 파일로 바꿉니다(새 판을 그 폴더에 넣기만 하면 됨). 판이 바뀐 차주는 다음 적용 때 새 판으로 보고서를 새로 만들고 예전 보고서는 남깁니다.

② 문서 AI — Gemini API 키(무료)

문서 읽기는 구글 Gemini 가 가장 정확하고 빠릅니다. 스캔 PDF 에서 특히 차이가 납니다.

  1. aistudio.google.com 에 구글 계정으로 로그인합니다.
  2. 왼쪽 메뉴의 Get API key → Create API key 를 눌러 키를 만들고 복사합니다.
  3. 프로그램 준비 표 「문서 AI」 행의 AI 설정 펼치기.
  4. AI 에서 「Gemini — API 키 입력」을 고르고, 모델은 목록 맨 위 그대로 두고, 키 칸에 붙여 넣고 저장.
  5. 상태가 ✓ 설정됨이면 끝. 무료 키는 하루 사용량 한도가 있어, 많이 돌리면 다음 날 풀립니다.

③ 판단 AI — Codex 또는 Claude(권장)

  1. 같은 펼친 칸의 판단 AI 에서 Codex 또는 Claude 를 고르고 저장.
  2. 「로그인 필요」가 뜨면 로그인 창 열기 → 열린 창에서 본인 계정으로 로그인 → 준비 표 상태 확인.
  3. 프로그램이 이 PC 에 없으면 준비 표 아래 자동 설치가 먼저 돕니다. 고르지 않으면 읽기 AI(Gemini)가 판단도 합니다.

④ 지지옥션 · ⑤ 인포케어 로그인

  1. 준비 표의 지지옥션 탭 열기 → 맨 위 「지지옥션」 탭에서 회사 계정으로 로그인합니다.
  2. 인포케어도 인포케어 탭 열기 → 로그인.
  3. 「차주 작업」 탭으로 돌아오면 로그인 칸이 저절로 ✓ 로그인됨으로 바뀝니다. 로그인은 프로그램을 껐다 켜도 유지됩니다.

두 사이트는 사람이 쓰는 속도로만 요청합니다. 너무 많이 누르면 사이트가 막을 수 있으니, 「모으기」는 한 번 누르고 진행 띠를 기다립니다.

⑥ 국토교통부 실거래 API — 공공데이터포털

주변 실거래(거래사례)를 받습니다. 키 하나로 아래 서비스를 모두 쓰지만, 서비스마다 따로 「활용신청」을 해야 합니다.

  1. data.go.kr 회원가입·로그인.
  2. 검색창에 아래 이름을 하나씩 넣고 들어가 활용신청(목적: 업무 참고 등). 모두 자동 승인됩니다.
  3. 마이페이지 → 활용신청 목록 → 아무 항목이나 열면 일반 인증키(Decoding) 가 있습니다. 8개 모두 같은 키입니다.
  4. 준비 표 「국토교통부 API」 칸에 붙여 넣고 저장. 신청 직후 몇 분~1시간은 「등록되지 않은 키」가 날 수 있습니다(포털 반영 지연).

⑦ 디스코 로그인

  1. disco.re 에 개인 계정을 만듭니다(무료).
  2. 준비 표 「디스코 로그인」 행에 이메일·비밀번호 → 저장 → 로그인 확인.
  3. 국토부 실거래와 디스코 실거래를 함께 받아 거래사례 후보가 늘어납니다.

⑧ V-World 키 — 브이월드

  1. vworld.kr 회원가입·로그인 → 상단 오픈API → 인증키 발급.
  2. 활용할 API 고르는 칸에서 2D 데이터(연속지적도), 이미지(정적 지도), 검색·주소 좌표(Geocoder) 를 체크합니다. 서비스 URL 칸은 http://localhost 로 적어도 됩니다.
  3. 발급된 키를 준비 표 「V-World 키」 칸에 넣고 저장.
  4. 쓰임: 디스코가 본건 반경 안 필지 목록을 받는 데 씁니다(없으면 거래사례가 적게 나옵니다). 카카오 키가 없을 때 위치도 지도도 여기서 만듭니다.

⑨ 카카오 REST 키(선택)

  1. developers.kakao.com 로그인 → 내 애플리케이션 → 애플리케이션 추가(이름 아무거나).
  2. 앱 설정의 앱 키에서 REST API 키를 복사합니다. 지도가 안 나오면 앱 설정에서 카카오맵 사용을 켭니다.
  3. 준비 표 「카카오 REST 키」 칸에 넣고 저장. 위치도(템플릿 4.사진)를 카카오 지도로 만듭니다.

⑩ 검증 AI · CLI 연결(선택)

  • 검증 AI: 기본은 자동 — 이 PC 에 있는 AI 중 읽기 AI 와 다른 것(Gemini 키 → Codex → Claude 순, 없으면 같은 AI 의 다른 모델)으로, 문서 추출이 끝날 때마다(버튼·자료 준비·CLI 모두) 뒤에서 다시 읽어 물건 주소·용도·금액이 같은지 맞춰 봅니다. 결과는 물건지 › PBC 문서 아래 「문서 검증」 상자. 특정 AI 를 쓰려면 「AI 설정 펼치기」의 검증 AI 에서 고르고, 끄려면 「끔」.
  • CLI 연결: Claude Code·Codex·Claude 데스크톱 앱을 쓰는 사람만 연결 설치. 자세한 것은 9장.

4. 분기 시작

폴더 열기→분기 폴더 04. 26.4Q\01. MGAMCO\03. WP→평가자(내 이름) 선택→공유 폴더에서 내 차주 자료 가져오기
  1. 분기 폴더를 열면 Assign 엑셀을 읽어 내 차주 목록이 뜹니다. 추출 전·추출 중·기입 전·기입 완료 개수가 위에 보입니다.
  2. 끝난 차주는 폴더 이름 뒤에 _완료 를 붙여도 됩니다(엑셀 보고서를 닫고). 도구가 같은 차주로 알아보고 보고서·수집 엑셀·위치도 경로를 새 이름으로 따라갑니다.
  3. 공유 폴더에서 내 차주 자료 가져오기를 누르면 공유 VDR·등기부에서 내 차주 서류를 찾아 미리보기를 보여 줍니다. 확인한 뒤 실제로 가져오면 차주마다 03. WP\{평가자}\NN. 차주 폴더가 생깁니다.
  4. 공유 폴더에 없는 서류는 그 차주 폴더에 직접 넣습니다. 목록에서 「직접 넣음」으로 표시됩니다.
  5. 일괄 통계는 목록의 모든 차주 낙찰통계를 인포케어에서 한 번에 받습니다.
  6. 분기 차주 목록 「재감정」: Assign 의 재감정요청 여부(EQ열)를 그대로 보입니다(불필요 · 탁상 자문 요청 · 정밀 자문 요청 · 정식감정 요청). 새 감정평가서를 가져와 「추출」했을 때 기준일이 감정 수령 기준일(목록 오른쪽 위, 26.4Q 기본 2024-10-06) 이후면 수령으로 바뀝니다. 순서는 불필요 → 수령 → 요청. 보고서를 기입한 뒤 감정평가서를 새로 추출했으면 「새 감정평가서 — 다시 기입」이 뜹니다.
  7. 「감정서」: Assign 의 감정서 유형(외부감정서 · 경공매감정서 · 금고자체 감정서 · KB시세 · 금고제시 탁상감정서 · 자료없음)을 그대로 보입니다. 이 값으로 보고서 「(3) 감정평가」의 구분(외부감정/MG자체감정)·종류(대출당시 구감정/경공매 감정평가/탁상감정)와 「(2) 적용감정가」(외부감정서/경공매감정서/KB시세)를 정해 기입합니다 — 외부감정서는 감정평가서 기준일이 경매개시일 이후면 경공매, 아니면 대출당시 구감정. 탁상·금고자체·자료없음은 적용감정가를 정하지 않고 「사람이 채울 칸」으로 둡니다.
  8. 「완료」 체크: 평가를 끝낸 차주는 목록 왼쪽 「완료」 칸을 체크하면 단계가 「완료」로 바뀝니다(위 거르기 단추에도 「완료」). 끄면 원래 단계로 돌아갑니다. 이 PC 에만 남습니다.
  9. 「특이사항」: 분기 폴더(01. MGAMCO)의 DataDisk 엑셀 「차주」 시트(차주비고 · 평가 comment · 매각제외 · 전건/일부제외 · 전분기 중복 · 평가 Assign)와 담보지번 실사 엑셀(「확인필요」 시트 · 지번별 비고)에서 차주별로 모아 짧게 보입니다 — 마우스를 올리면 전문, 자세히를 누르면 구분·관리번호·내용·근거 표. DataDisk 담당이 Assign 표와 다르면 빨갛게 「DataDisk 담당 ○○」. 파일 이름이 바뀌어도(날짜·_v3.0·(1)) 이름 규칙에 맞는 것 중 최근 저장한 파일을 읽습니다.

목록에서 차주를 누르면 그 차주 작업 화면으로 갑니다.

5. 차주 한 명 작업

① 한 번에 모으기

1단계 물건지 맨 위 자료 준비(한 번에 모으기)를 누릅니다. 아래를 순서대로 알아서 합니다. 차주 한 명에 보통 5~10분입니다.

문서 추출→공시지가·KB시세→지지옥션 본건 조회→용도 제안→낙찰사례 수집→거래사례 조회→제안 계산

이미 같은 주소·검색 용도로 모아 둔 낙찰·거래사례가 있으면 다시 모으지 않고 그것을 씁니다(새로 모으려면 그 단계의 다시 모으기). 용도를 정하지 못하면 낙찰·거래사례만 건너뛰고 끝까지 갑니다(끝나면 「④ 낙찰사례 검색 용도에서 고르세요」가 뜹니다). 검증 AI 와 주소 대조는 문서 추출이 끝나는 순간 뒤에서 같이 돕니다. 파일에는 아직 아무것도 쓰지 않습니다.

② 단계마다 확인 — 왼쪽 단계를 위에서부터

상자마다 제목 띠가 있고, 파란 버튼은 그 상자에서 지금 눌러야 할 다음 버튼입니다. 이미 한 것은 흰색 「다시 …」입니다.

  1. 1 물건지 — 문서와 물건 주소
    • 볼 것: 「PBC 문서」 타일의 추출 수. 타일을 누르면 문서별 추출 내용이 보입니다.
    • 볼 것: 토지 등기부 줄은 지번 옆에 지목이 보입니다. 「물건 묶기」 표의 결론. 등기부 = 감정평가서 = 수익권증서 주소를 AI 가 대조해 같은 물건이면 맞음, 다르면 틀림, 다른 점은 차이 사유에.
    • 할 것: 「틀림」인데 평가 대상이 아니면 — 감정평가서·신탁계약서 줄은 제외(그 주소만 빠지고 문서는 그대로, 되살리기로 되돌림), 등기부 줄은 문서 빼기. 물건이 여럿이면 지번마다 물건 번호(1~3)를 고르고 저장.
    • 할 것: 「문서 검증」 상자에 다른 칸이 있으면 칸마다 검증 값으로 또는 지금 값 유지. 노란 줄(물건 지번)을 먼저 봅니다.
    • 「공시지가·KB시세」「평가물건지 표」「위치도」 탭은 6장 참고.
  2. 2 경매/공매 — 본건 사건번호·법원·진행 상태. 사건이 없으면 비어 있습니다. 다시 받으려면 본건 사건 조회.
  3. 3 낙찰통계
    • 볼 것: 표의 출처(「프로그램 동봉」 = 분기 일괄 통계)와 초록으로 칠해진 칸(보고서에 쓸 기간·행정구역).
    • 할 것: 다른 칸을 쓰려면 그 칸을 누릅니다. 지역·용도를 바꾸면 바로 다시 계산됩니다. 「통계 없음」이면 인포케어에서 통계 가져오기.
  4. 4 낙찰사례 · 5 거래사례
    • 물건이 여럿이면: 맨 위 물건 1 물건 2 탭 — 본건 주소·검색 용도·다시 모으기·후보표·AI 추천·고른 사례가 모두 그 물건 것입니다. 물건 2·3 을 따로 모으지 않으면 물건 1 이 모은 사례에서 고릅니다. 「자료 준비」는 물건 2·3 도 모으되 주소·용도가 물건 1 과 같으면 같이 씁니다.
    • 볼 것: 「본건 주소」와 「검색 용도」(고른 용도만 보입니다 — 바꾸려면 목록 펼치기).
    • 볼 것: 거래사례 「본건 주소」 — 읍·면 주소는 리 칸까지 채워져 있어야 합니다(예: 백석읍 / 오산리). 리가 빠지면 거리 기준점이 다른 리로 잡힙니다. 거리는 본건 필지와 거래 필지 사이 지도 직선거리이고, 국토부가 지번을 가린 거래(4**)는 그 리·동 대표 지점까지 거리(대략값)입니다.
    • 낙찰사례는 지지옥션 상태가 종결·매각인 건만(진행·유찰·변경은 낙찰사례가 아님) — 표 사건번호 옆에 상태가 보입니다. 종결·매각이 10건이 안 되면 자동으로 넓힙니다: 가까운 구 3곳 → 그래도 모자라면 기간 3년. 모으는 중 결과 화면이 안 바뀌면 1분 안에 멈추고 로그인 확인을 안내합니다(지지옥션 로그인은 프로그램을 ×로 닫으면 이어지고, 강제 종료하면 풀립니다).
    • 할 것: 용도·기간·범위를 바꿨으면 다시 모으기. 표에서 쓸 사례를 체크(최대 5건·3건). AI 추천은 도구 순위대로 위에서 정확히 3건을 고릅니다(용도가 전혀 다른 건만 건너뜀, 이유는 「AI 추천」 표시에 마우스). 면적이 본건의 1/5배 미만·5배 초과인 사례는 「면적 차이 큼」으로 맨 뒤에 두고 고르지 않습니다. 건물 없이 토지만인 물건은 「토지 n순위」 — 낙찰사례 ① 면적당 감정가·면적당 낙찰가 모두 비슷(30% 안) ② 면적당 감정가 비슷 ③ 가까운 순, 거래사례는 면적당 감정가와 면적당 거래가가 비슷한 것 먼저, 그 안에서 ① 같은 용도지역 + 1km 안 ② 같은 용도지역 ③ 가까운 순. 낙찰사례 사건번호를 누르면 지지옥션 상세가 로그인 상태 그대로 화면 가운데 새 창으로 뜹니다. 거래사례도 「유사도」 칸에 종합 점수(위치·단가·면적·시점)가 있고 점수 높은 순으로 보입니다 — 여러 호실을 묶은 물건은 호실 평균 면적과 비교합니다. 표 머리글의 ⇅ 를 누르면 오름차순 → 내림차순 → 원래 순서, 표 위 「표 안에서 찾기」에 낱말을 넣으면 그 낱말이 모두 든 줄만 보입니다(「필터·정렬 풀기」로 원래대로). 표는 엑셀처럼 칸을 끌어 Ctrl+C 하거나 고른 사례 복사·보이는 n건 복사로 머리글째 복사해 엑셀에 붙여 넣으면 숫자는 숫자로 들어갑니다. 낙찰사례 엑셀 파일도 같은 15열(사건번호·주소·낙찰일자·감정평가액·낙찰가액·낙찰가율·건물면적·토지면적·입찰인수·비고·면적당 감정가/낙찰가·비고)입니다. 표에는 모은 사례가 모두 보이고(보고서 용도와 다르거나 1년이 지난 건은 「용도 다름」·「1년 지남」 표시 — 도구 자동 제안에선 빠지지만 직접·AI 로는 고를 수 있음), AI 가 고른 3건은 추천 순서대로 표 맨 위에 옵니다. AI 는 순서표가 아니라 사람처럼 저울질합니다 — 낙찰가율 차·단가 차·용도지역·지목(본건과 같음/비슷/조금 비슷/다름)·거리·시점을 같이 보고, 이유에 좋은 점과 아쉬운 점을 같이 적습니다. 낙찰사례 후보의 용도지역·지목은 처음 누를 때 디스코 필지 정보로 확인합니다. 거래사례 보고서 「주용도」는 토지 거래면 지목(전·답·임야 …).
    • 할 것: 표 위 「보고서 용도」 줄이 「정해야 함」이면 바꾸기 → 1 물건지 단계 「보고서 용도」 상자에서 고르고 저장. 토지와 건물이 같은 지번이면 건물 용도로 고릅니다.
  5. 6 코멘트 — 맨 위에 물건정보 표(건물내용연수 ~ 감정평가기준일 9칸, 보고서에 넣는 값 그대로), 아래에 감정평가서를 요약한 담보물 개요. 보고서에 들어갈 글이니 고쳐서 쓰면 됩니다.

③ 기입

중복 차주 — 전분기 보고서 이어받기: 7단계 기입 맨 아래 「전분기 보고서 이어받기」 상자. 직전 분기 폴더에서 이 차주 보고서를 찾아 보여 줍니다(없으면 다른 파일 고르기). 이어받기를 누르면 템플릿은 지금 고른 이번 분기 것 그대로 두고, 전분기 보고서에서 평가자가 적은 값·수식과 평가보고서·사진 시트 그림만 옮겨 새 보고서를 만듭니다. DataDisk·담보지번 같은 데이터 시트와 관리번호·담보 유형·VDR 물건번호는 이번 분기 값입니다. 평가물건지 물건 줄은 이번 분기 담보지번 목록과 지번으로 맞추고, 목록에 주소가 없으면 전분기 주소를 물건지 칸에 넣습니다. 예전 보고서·전분기 파일은 그대로 둡니다. 그 뒤 단계별 보고서에 적용을 누르면 그 단계 칸만 이번에 모은 값으로 바뀝니다.

평가물건지 값: 감정평가금액은 같은 지번 토지·건물이 일괄 평가면 건물 행에만(토지 행 비움), 따로 평가면 각자 행에 넣습니다. 공시지가(2개년)는 토지 행에만, KB시세는 아파트 호실 행에만 넣습니다. Assign 감정서 유형이 KB시세인 차주는 감정평가금액 칸을 비우고 KB시세 칸에만 넣습니다 — 공시지가 조회가 다른 필지를 찾았으면 넣지 않고 「사람이 채울 칸」으로 알립니다.

단계마다 확인하고 「보고서에 적용」: 물건지·경매/공매·낙찰통계·낙찰사례·거래사례·코멘트 단계 제목 옆에 상태와 보고서에 적용이 있습니다. 화면을 확인한 뒤 눌러야 그 단계가 보고서 파일에 들어갑니다(그 단계 칸을 먼저 비우고 씀 — 쓰지 않는 물건 2·3 블록도 비움). 상태: 「적용 전」 · 「적용됨」 · 「다시 적용 필요」(적용한 뒤 다시 조회하거나 다른 사례를 고름) · 「새 보고서에 적용 전」(템플릿을 바꿈). 왼쪽 단계 목록의 점도 같습니다(회색 테두리 = 적용 전, 초록 = 적용됨, 노랑 = 다시 적용).

보고서 파일: 파일 이름은 템플릿 「3.평가보고서」의 '보고서 파일명' 칸 수식대로 만듭니다(예: G018-1_MG_2026.4Q_경기_…_공명_Draft_이정원.xlsm, 같은 이름이 있으면 _수정1). 0단계에서 템플릿을 다른 판(예: v36 → v38)으로 고르면 다음 적용 때 그 템플릿으로 새 보고서를 만들고 모든 단계가 「적용 전」으로 돌아갑니다 — 예전 보고서는 지우지 않습니다. 같은 템플릿으로 새로 쓰고 싶으면 7 기입의 보고서 새로 만들기.

엑셀이 보고서를 열고 있으면 쓰기 전에 멈추고 화면 위에 빨간 상자로 알립니다 — 엑셀을 닫고 다시 누르세요. 기입할 때마다 차주 폴더 02. WP\기입기록.txt에 한 줄(시각·단계·템플릿 판·파일·대조 결과)이 남습니다.

7단계 기입의 한 번에 적용은 단계별 상태를 확인창으로 보여 준 뒤 모든 단계를 씁니다. 사람이 손본 보고서에 다시 적용해도 도구 칸만 바꾸고 백업을 남깁니다. 신탁공매저감 5% 는 신탁 물건이면 자동으로 들어가고, 추가저감은 보고서 엑셀에서 직접 적습니다.

안 쓰는 행 접기: 기입할 때마다 3.평가보고서의 안 쓰는 행을 그룹으로 접습니다(엑셀 왼쪽 + 로 펼침) — 채권현황의 빈 채권 행(과 같은 줄을 따라가는 (1) 매각금액 산정·(3) 예상배당금 줄), 쓰지 않는 물건 2·3 블록과 (2) 적용감정가 줄, 사례를 넣지 않은 낙찰·거래사례 줄. 사례가 한 건도 없으면 직접 채우도록 표를 그대로 둡니다. 건수가 늘어 다시 기입하면 다시 펼쳐집니다. 템플릿에 이미 있는 그룹(물건 2·3 블록 등)과 딱 맞으면 그 그룹을 접고, 아니면 새 그룹을 만듭니다.

6. 템플릿에 붙이기

물건지 › 위치도 탭에서 축척(50m·100m·200m·500m·1km·2km·3km·5km, 기본 200m)을 누르면 그 축척으로 바로 지도를 만들어 복사합니다. 칩에 마우스를 올리면 지도 가로 범위가 보입니다. 지도가 화면에 뜨고 클립보드에 들어갑니다. 템플릿 4.사진 시트 D5 칸을 누르고 Ctrl+V. 그림 크기는 칸과 같은 비율(813×534px)이라 늘리거나 줄일 필요가 없습니다. 파일은 02. WP\위치도.png에도 남습니다.

사진 맞춤 복사: 현장 사진·로드뷰 등을 캡처(Win+Shift+S)한 뒤 위치도 상자의 사진 맞춤 복사를 누르면, 클립보드 그림을 4.사진 칸 비율에 맞게 가운데를 기준으로 잘라 813×534px 로 다시 복사합니다. 4.사진의 빈 칸을 누르고 Ctrl+V 하면 크기 조정 없이 꽉 찹니다. 늘리지 않으므로 가로로 긴 캡처는 양옆, 세로로 긴 캡처는 위아래가 조금 잘립니다.

엑셀 네모에 넣기(더 쉬움): 보고서를 엑셀로 열고 사진 넣을 네모(2.Cover 가운데 · 4.사진 네 칸)를 한 번 클릭해 둔 뒤, 캡처하고 위치도 상자의 엑셀 네모에 넣기. 도구가 그 네모에 사진을 붙여 가운데를 잘라 테두리 안에 꽉 맞춥니다. 네모에 있던 그림(빈 자리 그림·전에 넣은 사진)은 바뀌고 「본건」 화살표는 사진 위에 남습니다. 저장은 엑셀에서. 칸 편집 중이면 Esc 후 다시.

10. 막혔을 때

지지옥션 본건 조회·낙찰사례가 「로그인 필요」로 실패

지지옥션 탭을 열어 로그인 상태를 보고, 풀렸으면 다시 로그인한 뒤 해당 단계의 다시 모으기.

낙찰통계가 안 받아짐

인포케어 탭 로그인을 먼저. 로그인돼 있으면 설정박스의 지역·용도를 확인합니다. 조건에 맞는 통계가 없으면 그렇게 표시됩니다.

문서 추출이 비어 있거나 틀림

그 문서 행을 누르고 추출로 다시 읽힙니다. 스캔 PDF는 시간이 더 걸립니다. 계속 안 되면 0단계에서 읽기 AI를 「Gemini — API 키 입력」으로 바꿔 봅니다. 신탁계약서·수익권증서·감정평가서 스캔본은 구글 API가 가장 정확하게 읽습니다.

거래사례 0건

0단계에 국토교통부 키와 디스코 계정, V-World 키가 있는지 확인. 반경은 1km에서 시작해 부족하면 3km까지 자동으로 넓힙니다. 그래도 0건이면 「검색 용도」를 넓게 다시 체크합니다.

위치도 버튼이 비활성

0단계에 카카오 REST 키 또는 V-World 키 중 하나가 있어야 합니다.

다른 차주를 시작하고 싶다

왼쪽 아래 화면 비우기는 화면만 비웁니다(파일 그대로). 저장 데이터 삭제는 이 차주의 추출·선택·수집 결과와 도구 산출물까지 지웁니다. PBC 원본과 사람이 저장한 파일은 남습니다.

터미널에서 「프로그램이 켜져 있지 않거나 CLI 연결이 꺼져 있습니다」

부동산업무도구를 먼저 켭니다. 켜져 있으면 0단계 「CLI 연결」 행이 켜짐인지 확인합니다.

Claude Code 가 「부동산업무도구 스킬이 없다」고 합니다

Claude Code 를 WSL 안에서 돌리는 경우입니다. 0.2.31 부터는 연결 설치가 WSL 홈에도 넣으니, 프로그램을 최신으로 올린 뒤 다시 한 번 누릅니다. 설치된 곳은 「CLI 연결」 행에 「WSL …」로 표시됩니다.

Claude 데스크톱 앱 채팅에 부동산업무도구 도구가 안 보입니다

연결 설치 뒤 앱을 완전히 종료(트레이 아이콘에서 Quit)하고 다시 켭니다. 「CLI 연결」 행에 「Claude 앱 ✓」가 있어야 합니다.
