1. 설치

  1. 설치 파일 rep-desktop-setup-0.2.25.exe를 받습니다. 정본은 GitHub Releases, 사본은 OneDrive 00. AI\004. 업무도구\부동산업무도구\에 있습니다.
  2. 실행하면 Windows SmartScreen 경고가 뜹니다(서명 없는 파일). 추가 정보 → 실행.
  3. 설치가 끝나면 「부동산업무도구」가 열립니다. 처음 켤 때 문서 AI 도구(Codex·Claude)를 자동으로 함께 설치합니다. 몇 분 걸릴 수 있습니다.
  4. 새 판이 나오면 0단계 준비 표 맨 위 「프로그램 업데이트」에서 업데이트 확인을 누르면 받습니다.

팀원 PC에는 WSL이나 파이썬을 따로 깔 필요가 없습니다. 필요한 것은 전부 설치 파일 안에 들어 있습니다.

4. 분기 시작

폴더 열기→분기 폴더 04. 26.4Q\01. MGAMCO\03. WP→평가자(내 이름) 선택→공유 폴더에서 내 차주 자료 가져오기
  1. 분기 폴더를 열면 Assign 엑셀을 읽어 내 차주 목록이 뜹니다. 추출 전·추출 중·기입 전·기입 완료 개수가 위에 보입니다.
  2. 공유 폴더에서 내 차주 자료 가져오기를 누르면 공유 VDR·등기부에서 내 차주 서류를 찾아 미리보기를 보여 줍니다. 확인한 뒤 실제로 가져오면 차주마다 03. WP\{평가자}\NN. 차주 폴더가 생깁니다.
  3. 공유 폴더에 없는 서류는 그 차주 폴더에 직접 넣습니다. 목록에서 「직접 넣음」으로 표시됩니다.
  4. 일괄 통계는 목록의 모든 차주 낙찰통계를 인포케어에서 한 번에 받습니다.

목록에서 차주를 누르면 그 차주 작업 화면으로 갑니다.

5. 차주 한 명 작업

① 한 번에 모으기

1단계 물건지 맨 위 자료 준비(한 번에 모으기)를 누릅니다. 아래를 순서대로 알아서 합니다. 차주 한 명에 보통 5~10분입니다.

문서 추출→공시지가·KB시세→지지옥션 본건 조회→용도 제안→낙찰사례 수집→거래사례 조회→제안 계산

용도를 못 정하면 중간에 묻습니다. 고르면 이어서 돕니다. 파일에는 아직 아무것도 쓰지 않습니다.

② 단계마다 확인

  • 물건지 — PBC 문서 타일을 누르면 추출 내용이 보입니다. 잘못 읽은 문서는 추출로 다시 읽힙니다. 「물건 묶기」 표에는 등기부·신탁계약서(신탁부동산)·수익권증서(신탁재산표시)·감정평가서의 지번이 한 줄씩 놓이고, 등기부와 같은 지번이면 등기부 일치가 붙습니다. 신탁계약서에 부동산 별지가 없어도 수익권증서 행으로 신탁 쪽 주소를 볼 수 있습니다. 「등기부와 안 맞음」은 등기부에 없는 필지라는 뜻이라, 평가 대상이 아니면 그 행을 「빼기」. 물건이 여럿이면 지번마다 물건 번호(1~3)를 정합니다.
  • 경매/공매 — 본건 사건번호·법원·진행 상태. 사건이 없으면 비어 있습니다.
  • 낙찰통계 — 설정박스에서 지역·용도를 바꾸면 바로 다시 계산됩니다. 적용할 칸(기간·행정구역)을 누릅니다.
  • 낙찰사례 · 거래사례 — 「검색 용도」를 체크하고 다시 모으기로 다시 받을 수 있습니다. 표에서 쓸 사례를 체크합니다. AI 추천은 단가·낙찰가율·위치가 비슷한 것을 골라 줍니다.
  • 코멘트 — 감정평가서를 요약한 담보물 개요. 고쳐서 쓰면 됩니다.

③ 기입

7단계 기입에서 한 번에 적용을 누르면 템플릿을 복사해 보고서 파일을 만들고, 지금까지 고른 값을 도구 칸에 씁니다. 사람이 손본 보고서에 다시 적용해도 도구 칸만 바꿉니다. 저감(추가 저감 사유·비율)은 기입 화면 위쪽에서 넣습니다.

7. 빠른 조회

차주 등록 없이 지역 하나로 통계·낙찰사례·거래사례만 볼 때 씁니다.

  1. 왼쪽 빠른 조회 → 주소 입력(동까지만 넣어도 됩니다. 예: 인천 미추홀구 주안동) → 시작.
  2. 단계가 낙찰통계·낙찰사례·거래사례 3개로 줄어듭니다. 낙찰사례·거래사례는 용도를 고르고 조회합니다.
  3. 차주 작업으로 돌아가려면 분기 차주 목록.

9. CLI 연결(선택)

Claude Code·Codex 같은 AI 터미널을 쓰는 사람은 프로그램을 터미널에서 말로 부릴 수 있습니다. 안 쓰는 사람은 이 장을 건너뜁니다. 프로그램은 그대로입니다.

  1. 0단계 준비 표 「CLI 연결」 행에서 스킬 설치. Claude Code(~\.claude\skills)와 Codex(~\.codex\skills)에 「부동산업무도구」 스킬이 들어갑니다. 한 번만.
  2. 부동산업무도구를 켜 둡니다. 켜져 있어야 명령이 닿습니다.
  3. 터미널에서 평소처럼 말합니다. 예: 김주연 자료 준비해줘, 10. 김주연 위치도 넓게 만들어, 이번 분기 차주 목록 보여줘. AI 가 스킬을 읽고 프로그램에 명령을 보냅니다.
  4. 진행은 프로그램 화면 로그에 그대로 찍힙니다. 화면 버튼을 누른 것과 똑같이 움직이고, 결과 파일도 같은 곳에 갑니다.

10. 막혔을 때

지지옥션 본건 조회·낙찰사례가 「로그인 필요」로 실패

지지옥션 탭을 열어 로그인 상태를 보고, 풀렸으면 다시 로그인한 뒤 해당 단계의 다시 모으기.

낙찰통계가 안 받아짐

인포케어 탭 로그인을 먼저. 로그인돼 있으면 설정박스의 지역·용도를 확인합니다. 조건에 맞는 통계가 없으면 그렇게 표시됩니다.

문서 추출이 비어 있거나 틀림

그 문서 행을 누르고 추출로 다시 읽힙니다. 스캔 PDF는 시간이 더 걸립니다. 계속 안 되면 0단계에서 읽기 AI를 「Gemini — API 키 입력」으로 바꿔 봅니다. 신탁계약서·수익권증서·감정평가서 스캔본은 구글 API가 가장 정확하게 읽습니다.

거래사례 0건

0단계에 국토교통부 키와 디스코 계정, V-World 키가 있는지 확인. 반경은 1km에서 시작해 부족하면 3km까지 자동으로 넓힙니다. 그래도 0건이면 「검색 용도」를 넓게 다시 체크합니다.

위치도 버튼이 비활성

0단계에 카카오 REST 키 또는 V-World 키 중 하나가 있어야 합니다.

다른 차주를 시작하고 싶다

왼쪽 아래 화면 비우기는 화면만 비웁니다(파일 그대로). 저장 데이터 삭제는 이 차주의 추출·선택·수집 결과와 도구 산출물까지 지웁니다. PBC 원본과 사람이 저장한 파일은 남습니다.

터미널에서 「프로그램이 켜져 있지 않거나 CLI 연결이 꺼져 있습니다」

부동산업무도구를 먼저 켭니다. 켜져 있으면 0단계 「CLI 연결」 행이 켜짐인지 확인합니다.

프로그램이 멈춘 것 같다

진행 띠의 걸린 시간이 계속 늘면 돌고 있는 겁니다. 멈추려면 중지. 창을 닫고 다시 켜면 마지막 차주 폴더와 로그인은 그대로입니다.
